# FraudShield AI Dataset

## Download Instructions

The raw data for this project is the **Credit Card Fraud Detection** dataset provided by the Machine Learning Group - ULB (Université Libre de Bruxelles) on Kaggle.

1. Go to the Kaggle dataset page:
   [Credit Card Fraud Detection on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
2. Download the archive.
3. Extract `creditcard.csv` into this directory (`ml/data/`).

> **Note:** The file is approximately 150MB uncompressed and is intentionally not tracked in version control.
